# 复核策略

## 目的
模型只回答"违约概率是多少"。策略技能回答"这单该怎么处理"，并且必须
把高风险决策交给人，不允许自动拒贷。

## 分级规则（按优先级从高到低）
1. 数据审计为 `error` → **退回补件**，不进入评分与决策。
2. 数据审计为 `warn` → 至少进入**人工复核**，不允许自动通过。
3. `p ≥ 建议拒绝线` → **建议拒绝（必须人工确认）**，优先级最高。
4. `p ≥ 复核线` → **转人工复核**。
5. `p` 落在复核线 ±0.02 内 → **转人工复核**（边界不确定）。
6. 其余 → **自动通过**（低风险快速通道）。

## 容量约束
复核线由验证集上"风险分最高的 `capacity` 比例"确定（默认 15%），
使复核队列长度可控；建议拒绝线取复核容量的 1/3。策略技能不重新训练模型，
只消费模型输出的阈值。

## 输出约定
- `band`：A（低）/ B（中）/ C（高）
- `action`：自动通过 / 人工复核 / 建议拒绝并人工确认 / 退回补件
- `review_required`：布尔值
- `priority`：数值越大越先看
- `rationale`：一句话说明依据

## 边界
- 策略是"建议"不是"决定"：`建议拒绝` 必须由人工签署。
- 不处理反欺诈、额度定价和合规审查，这些在原型范围之外。
